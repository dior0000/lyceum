# 💘 Лицей БГУ · Знакомства (Telegram Mini App)

Мини-приложение внутри Telegram-бота для знакомств лицеистов: анкета с классом, полом и фото, лента противоположного пола, лайки, мэтчи с уведомлениями и модерация жалоб.

**Стек:** Node.js (Express) + встроенный SQLite (`node:sqlite`) + [grammY](https://grammy.dev) (Telegram Bot API). Фронтенд — чистый HTML/JS/CSS с Telegram WebApp API.

## Требования

- Node.js **22.5+** (используется встроенный модуль `node:sqlite`)

## Шаг 1. Создать бота

1. Открой [@BotFather](https://t.me/BotFather) → `/newbot` → придумай имя и username бота.
2. Скопируй **токен** (вида `1234567890:AAAA...`).
3. Узнай свой Telegram ID у [@userinfobot](https://t.me/userinfobot) — он будет ID администратора.

## Шаг 2. Настроить проект

```bash
npm install
copy .env.example .env
```

Заполни `.env`:

```
BOT_TOKEN=токен_от_BotFather
ADMIN_ID=твой_telegram_id
WEBAPP_URL=https://адрес-приложения   # см. шаг 3
PORT=3000
```

## Шаг 3. HTTPS-адрес (обязателен для Mini App)

Telegram открывает мини-приложения только по HTTPS.

**Для теста** — туннель к локальному серверу, например [cloudflared](https://github.com/cloudflare/cloudflared/releases):

```bash
cloudflared tunnel --url http://localhost:3000
```

Он выдаст адрес вида `https://xxxx.trycloudflare.com` — впиши его в `WEBAPP_URL` в `.env` (или используй ngrok: `ngrok http 3000`).

**Для постоянной работы** — задеплой на [Railway](https://railway.app), [Render](https://render.com) или любой VPS и впиши выданный домен. Важно: `data.sqlite` и папка `uploads/` должны лежать на постоянном диске (на Railway/Render подключи Volume), иначе анкеты пропадут при перезапуске.

## Шаг 4. Запуск

```bash
npm start
```

Бот начнёт отвечать на `/start` кнопкой «💘 Открыть анкеты».

Чтобы кнопка Mini App была ещё и в меню чата: @BotFather → `/mybots` → выбери бота → **Bot Settings → Menu Button** → укажи `WEBAPP_URL`.

> После смены `WEBAPP_URL` перезапусти сервер (`Ctrl+C` → `npm start`).

## Возможности

- **Регистрация:** имя (подставляется из Telegram), класс — подразделы 10-х и 11-х (Фил, Ист, Общ, Био1, Био2, Хим, ЭГ, ИМ, ИФ, М1, М2, Ф), пол, «ищу пару», обязательное фото (файлом или аватарка из Telegram), превью анкеты.
- **Лента:** мальчикам — девочки, девочкам — мальчики; только те, у кого включено «ищу пару»; каждая анкета показывается один раз; лайк кнопками или свайпом.
- **По классам:** кнопка «🏫 Профили по классам» над лентой — выбор класса (подразделы 10-х и 11-х) и выезжающая панель с профилями этого класса (фото и имя), лайк прямо из панели.
- **Мэтчи:** при взаимном лайке обоим приходит сообщение от бота с фото и ссылкой на профиль; список мэтчей в приложении.
- **Профиль:** редактирование анкеты, переключатель «ищу пару», удаление анкеты.
- **Модерация:** кнопка 🚩 на карточке; после 3 жалоб анкета скрывается до решения администратора; один Telegram-аккаунт = одна анкета (привязка по подписанному `initData`).

## Команды администратора (в чате с ботом)

| Команда | Действие |
|---|---|
| `/admin` | список команд |
| `/stats` | статистика: анкеты, лайки, мэтчи, жалобы |
| `/reports` | список анкет с жалобами |
| `/ban <tg_id>` | заблокировать пользователя |
| `/unban <tg_id>` | разблокировать |
| `/approve <tg_id>` | вернуть скрытую анкету в ленту и сбросить жалобы |

О каждой жалобе администратору приходит уведомление от бота.

## Структура

```
src/server.js   — Express API + запуск бота
src/bot.js      — Telegram-бот: /start, админ-команды, уведомления о мэтчах
src/auth.js     — проверка подписи initData (HMAC)
src/db.js       — схема SQLite (users, likes, reports)
public/         — Mini App (index.html, app.js, style.css)
uploads/        — фотографии анкет (создаётся автоматически)
data.sqlite     — база данных (создаётся автоматически)
```
