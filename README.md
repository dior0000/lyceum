# 💃 Апошні вальс — Telegram Mini App Ліцэя БДУ

Пошук пары на вальс апошняга званка: анкета з класам, полам і фота, стужка супрацьлеглага полу, прагляд профіляў па класах, лайкі, мэтчы з апавяшчэннямі і мадэрацыя скаргаў. Інтэрфейс цалкам на беларускай мове.

**Бот:** [@aposhni_vals_bot](https://t.me/aposhni_vals_bot) · **Прод:** https://lyceum-dusky.vercel.app

## Стэк

- **Vercel** — хостынг (serverless-функцыя `api/index.js` + статыка з `public/`)
- **Neon Postgres** — база даных (анкеты, лайкі, скаргі, фота)
- **grammY** — Telegram-бот праз webhook `/api/tg-webhook`
- **Express + multer** — API, фота сціскаюцца ў браўзеры і захоўваюцца ў базе (`bytea`)

## Як гэта працуе

- Аўтарызацыя — подпіс `initData` Telegram (HMAC), правяраецца на кожны запыт. Адзін акаўнт Telegram = адна анкета.
- Фота аддаюцца па адрасе `/api/photo/<uuid>` з нязменным кэшам; UUID выпадковы, таму спасылку не падабраць.
- Кожны push у `main` аўтаматычна дэплоіцца на Vercel.

## Зменныя асяроддзя (Vercel → Settings → Environment Variables)

| Зменная | Прызначэнне |
|---|---|
| `BOT_TOKEN` | токен бота ад @BotFather |
| `WEBAPP_URL` | адрас праграмы, напр. `https://lyceum-dusky.vercel.app` |
| `WEBHOOK_SECRET` | сакрэт для праверкі запытаў Telegram |
| `ADMIN_ID` | Telegram ID адміністратара |
| `lyceum_DATABASE_URL` | дадаецца аўтаматычна пры падключэнні Neon |

Пасля змены зменных патрэбны **Redeploy**.

## Пасля змены адраса або токена

```powershell
# webhook
curl -X POST "https://api.telegram.org/bot<TOKEN>/setWebhook" -H "Content-Type: application/json" ^
  -d "{\"url\":\"https://<домен>/api/tg-webhook\",\"secret_token\":\"<WEBHOOK_SECRET>\"}"

# кнопка меню ў чаце
curl -X POST "https://api.telegram.org/bot<TOKEN>/setChatMenuButton" -H "Content-Type: application/json" ^
  -d "{\"menu_button\":{\"type\":\"web_app\",\"text\":\"Апошні званок\",\"web_app\":{\"url\":\"https://<домен>\"}}}"
```

## Магчымасці

- **Рэгістрацыя:** імя (падстаўляецца з Telegram), клас — кнопкі паралеляў 10-х і 11-х (Фил, Ист, Общ, Био1, Био2, Хим, ЭГ, ИМ, ИФ, М1, М2, Ф), пол, «шукаю пару», абавязковае фота (файлам або аватарка з Telegram), прагляд анкеты перад адпраўкай.
- **Стужка:** хлопцам — дзяўчаты, дзяўчатам — хлопцы; толькі тыя, у каго ўключана «шукаю пару»; кожная анкета паказваецца адзін раз; лайк кнопкамі або свайпам.
- **Па класах:** кнопка «🏫 Профілі па класах» — паралель → клас → карткі профіляў з фота і імем, лайк адразу адтуль.
- **Мэтчы:** пры ўзаемным лайку абодвум прыходзіць паведамленне ад бота з фота і спасылкай на профіль; спіс мэтчаў у праграме.
- **Профіль:** рэдагаванне анкеты, пераключальнік «шукаю пару», выдаленне анкеты.
- **Мадэрацыя:** кнопка 🚩 на картцы; пасля 3 скаргаў анкета хаваецца да рашэння адміністратара.

## Каманды адміністратара (у чаце з ботам)

| Каманда | Дзеянне |
|---|---|
| `/admin` | спіс каманд |
| `/stats` | статыстыка: анкеты, лайкі, мэтчы, скаргі |
| `/reports` | спіс анкет са скаргамі |
| `/ban <tg_id>` | заблакаваць карыстальніка |
| `/unban <tg_id>` | разблакаваць |
| `/approve <tg_id>` | вярнуць схаваную анкету ў стужку і скінуць скаргі |

## Лакальны запуск (неабавязкова)

Патрэбны `.env` (гл. `.env.example`) і доступ да базы. Спачатку зніміце webhook, інакш polling атрымае памылку 409:

```powershell
curl "https://api.telegram.org/bot<TOKEN>/deleteWebhook"
npm install
npm start
```

Каб вярнуць прод — зноў выканайце `setWebhook` з каманды вышэй.

## Структура

```
api/index.js    — уваход serverless-функцыі Vercel
src/app.js      — Express-праграма: API, webhook, фота
src/bot.js      — бот: /start, каманды адміна, апавяшчэнні
src/auth.js     — праверка подпісу initData
src/db.js       — злучэнне з Postgres і схема табліц
public/         — Mini App (index.html, app.js, style.css)
vercel.json     — маршрутызацыя /api/* на функцыю
```
